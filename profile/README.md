## About

**KScripts** builds scripts and tools that do one job and do it well. The code stays short, readable
and easy to change, and everything we publish is open for anyone to use, fork and improve.

<br>

## Principles

<table>
  <tr>
    <td width="33%" valign="top">
      <h4>Lightweight</h4>
      Quick to set up and quick to run. No heavy dependencies unless the job needs them.
    </td>
    <td width="33%" valign="top">
      <h4>Readable</h4>
      Clear structure and honest documentation. You should understand a script in minutes.
    </td>
    <td width="33%" valign="top">
      <h4>Open</h4>
      Free to use and modify. Issues and pull requests are always welcome.
    </td>
  </tr>
</table>

## Quick start

```bash
git clone https://github.com/KokiScripts/<repository>.git
cd <repository>
```

Then follow the README inside the repository for installation and usage.

<br>

## Contributing

1. Fork the repository you want to improve.
2. Create a branch for your change.
3. Commit with a clear message and open a pull request.

Found a bug or have a suggestion? Open an issue in the repository it relates to.
