## About

KScripts is a small open-source organization. We write scripts and tools that do one job
and do it well, and we keep the code short enough to read.

Everything here is free to use, fork and change.

## Projects

See the [repositories page](https://github.com/orgs/KokiScripts/repositories) for the full list.

## Using a project

```bash
git clone https://github.com/KokiScripts/<repository>.git
cd <repository>
```

Each repository's README covers setup and usage.

## Contributing

Pull requests and bug reports are welcome. Fork the repository, make your change on a
branch, and open a pull request. For bugs or ideas, open an issue in the repository
the problem is in.
